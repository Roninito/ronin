06

Architecture Highlights

Production-ready architecture with governance, observability, and battle-tested patterns.

🔄 SAR Execution Model (Sense → Analyze → Respond)

Every duty runs through a unified execution loop with built-in governance:

  • SENSE — Pull signals from sensors (cron, webhooks, file watches, events)
  • ANALYZE — Reason over context with AI, apply token budgets, resolve models
  • RESPOND — Execute tools, write memory, emit events, trigger other duties

🛡️ Built-in Governance

Token Guards: Automatic budget enforcement prevents runaway model usage
Execution Tracking: Full audit trail of every duty execution with timing, costs, and results
Model Resolution: Intelligent model selection based on task complexity and budget
Middleware Stack: Composable middleware for logging, budgets, trimming, and persistence

Privacy-First Design

100% Local Operation: Run entirely offline with local Ollama models. No data leaves your machine.

Cloud-Optional: Add cloud providers (Anthropic, OpenAI, Gemini) only when needed. Automatic failback to local models.

SQLite Storage: All data stored locally in ~/.ronin/ronin.db. Full ownership and control. Easy backup and migration.

Getting Started

# Install Bun curl -fsSL https://bun.sh/install | bash # Clone Ronin git clone https://github.com/yourusername/ronin.git cd ronin # Install dependencies bun install # Initialize configuration bun run ronin init # Start the system bun run ronin start # Access web UI # Navigate to http://localhost:3777
Quick Start Options

Local-Only Mode: Install Ollama and run completely offline. Perfect for privacy-focused deployments.

Cloud-Enabled Mode: Add Anthropic/OpenAI API keys for more powerful models. Local models used as fallback.

Desktop App: Use Electrobun wrapper for native desktop experience with system tray and notifications.
